## Как это работает
* При запуске джобы Jenkins скачивает актуальный код из ветки.
* Происходит сборка через Maven и изоляция паролей тестов.
* Готовый `.jar` копируется в рабочую директорию хоста `/opt/petclinic/`.
* Через проброшенный контейнер-инструмент выполняется команда `systemctl restart petclinic` на хост-системе.
* Цикл `curl` проверяет живость процесса. Если статус `200` получен — деплой успешен.
