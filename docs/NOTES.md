# Документация по автоматизации деплоя Spring PetClinic

## Что было сделано (Этап 2)
1. **Тестирование и сборка**: Настроен полноценный стейдж сборки артефакта и публикации результатов JUnit-тестов.
2. **Управление службой**: Создан конфигурационный файл `deploy/petclinic.service` для управления через systemd хоста.
3. **Smoke Test**: Интегрирована проверка доступности эндпоинта Actuator Health с циклом ожидания до 15 попыток.
4. **Сравнение способов автозапуска**: 
   - *GitHub Webhooks* (Выбранный вариант): моментально реагирует на пуш за счёт HTTP-сигнала со стороны GitHub, не нагружает сервер Jenkins лишними запросами.
   - *SCM Polling*: периодически опрашивает сервер Git по cron-расписанию, создаёт задержки в деплое и лишнюю нагрузку на сеть.
